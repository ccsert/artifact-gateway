## Design Specificity Verdict

当前登录和公共浏览已经为 Artifact Gateway 而写：公开只读边界、可信来源、仓库类型、OCI/Maven/npm/PyPI 等格式、摘要与使用命令都具有真实产品语义。

但认证后的管理内页仍较像通用 Ant Design 后台。产品特色主要停留在文案和数据模型，还没有沉淀成贯穿控制台的视觉语法，例如“来源 → 扫描 → 隔离 → 晋级 → 分发”的生命周期表达。

确定性扫描发现 2 条 warning，均来自同一次侧栏折叠：`Layout.tsx:319` 动画 `width`，`Layout.tsx:379` 动画 `margin-left`。它们确实可能触发布局重算，但目前只能判定为代码风险，不能声称已经复现卡顿。全局 reduced-motion 已提供降级。

浏览器可正常显示当前登录、公共目录和一个公开 Go 制品详情，公开 API 数据完整且 console 无 error。由于未使用用户凭据，受保护管理页只能验证其正确重定向。浏览器安全策略禁止可变脚本注入，因此没有可靠的检测覆盖层，不能把空 console 解释成页面没有问题。

## Overall Impression

这是已完成一次有效重构、但尚未完成系统性收尾的产品。最值得做的不是换颜色或重新画 Dashboard，而是把现有设计系统真正贯穿到响应式布局、可访问性、复杂任务层级和错误恢复。

## What's Working

- 产品语义真实：格式、仓库类型、digest、公开读取边界和复制用法都围绕制品消费任务组织。
- 视觉基础已经成型：深色表面层级、青色强调、运行/治理/管理分组、Ant Design 表格和共享 Metric/Filter 组件形成稳定基线。
- 安全与反馈基础不错：登录预验证、危险操作确认、Loading/Error/Empty 共享组件、路由恢复与主题/语言切换都已经存在。

## Priority Issues

### [P1] 认证后 App Shell 存在移动端与 200% Zoom 回退风险

固定 224/68px 侧栏与等宽 `margin-left` 通过内联样式控制；现有窄屏 CSS 没有明确的移动 Drawer 方案。`MetricStrip` 的内联列数也可能压过移动端单列规则。

- Why it matters：390px 和高倍缩放下主内容可能只剩极窄区域，影响值守和治理操作。
- Fix：窄屏改为可聚焦、Esc 可关闭、焦点可恢复的 Drawer；顶栏只保留菜单和搜索入口；移除内联栅格列数；补 390px 和 200% Zoom 回归。
- Suggested command：`$impeccable adapt`

### [P1] 辅助文字过小、过暗

10–12px 的说明文字大量使用 faint/低亮度颜色。历史截图已经显示这些文字在暗色背景上接近不可读；当前源码仍保留相同风险。

- Why it matters：低视力用户和低质量显示器会丢失状态、提示和说明，整体视觉也显得灰、糊、缺乏完成度。
- Fix：正文与帮助文字至少 12–14px；逐项测量 4.5:1 对比度；faint 仅用于真正禁用内容；状态不能只靠颜色和亮度表达。
- Suggested command：`$impeccable audit`

### [P2] 管理内页仍是通用的卡片、指标、筛选、表格组合

公共入口已经有清晰的信任叙事，但进入管理区后，仓库来源、完整性、风险、隔离与分发关系没有形成统一的视觉对象。

- Why it matters：用户能完成操作，却难以快速建立 Artifact Gateway 特有的心智模型。
- Fix：建立跨页面一致的制品信任与生命周期语言；Dashboard 从五个同权指标改为异常和待处理事项优先；关键概念提供就地解释。
- Suggested command：`$impeccable layout`，随后 `$impeccable onboard`

### [P2] 异步反馈和错误恢复没有形成闭环

Loading 缺少 `aria-live/status`；剪贴板失败可能静默；公共目录部分错误没有 Retry；部分错误仍可能直接显示状态码或后端文案。

- Why it matters：失败时用户不知道是否应等待、重试还是离开；屏幕阅读器用户更难确认动作结果。
- Fix：统一 live region；所有可重试读取提供 Retry；错误文案分为用户行动建议与诊断 ID；复制失败必须有可操作提示。
- Suggested command：`$impeccable harden`

### [P2] 侧栏折叠动画使用布局属性

检测器确认 `width` 与 `margin-left` 同步动画。虽然只有 220ms、且是用户主动触发，但复杂页面下可能造成布局重算。

- Why it matters：数据密集页面上可能出现掉帧，使产品失去工程工具应有的稳定感。
- Fix：优先改用 transform、固定轨道或 CSS Grid；用性能记录验证后再决定是否保留动画。
- Suggested command：`$impeccable optimize`

## Persona Red Flags

### Alex（高频专家）

- 有全局搜索、深链和复制命令，但没有可发现的快捷键或命令面板。
- 12 个导航入口仍需要频繁鼠标移动；缺少最近仓库、收藏和一致的批量操作。
- 分屏或平板值守可能被固定侧栏严重挤压。

### Sam（键盘、屏幕阅读器、低视力）

- 正向基础：全局 focus-visible、reduced-motion、较多 aria-label 和表单 label 已存在。
- 200% Zoom 下固定侧栏可能遮挡主内容。
- 10–11px 低亮度说明文字是明确风险。
- Loading、复制成功和失败缺少完整的辅助技术播报。

### Jordan（首次使用）

- 登录页直接出现 OIDC、Local session、Bearer Token、Native Hosted API v2，没有解释该选哪一种。
- 首次进入系统就面对运行、治理、管理共 12 个入口，缺少角色型起步路径。
- Hosted/Proxy/Group、digest、quarantine 等术语仍依赖领域经验。

## Cognitive Load

整体为中等认知负荷，8 项中明确失败 2 项：Dashboard 同时显示 5 个同权指标；公共目录最多出现“全部 + 7 个格式”筛选；认证后共有 12 个导航入口，虽然分为三组，但首次进入仍缺少任务导向。

值得保留的是面包屑、深链、当前仓库上下文、展开行与模式切换，它们已经很好地降低了工作记忆负担。

## Emotional Journey

- 登录：可信、克制，但技术术语让新手感到距离。
- Dashboard：平台健康状态是很好的安心锚点。
- 公共目录：公开只读与无需 Token 的边界说明，是当前最成熟的产品时刻。
- 低谷：连续零值、未启用和暂无数据会让移动端用户滚动很久仍不知道下一步。
- 结束：复制成功和部分保存反馈不错，但错误无 Retry 或直接暴露技术信息时，掌控感会突然中断。

## Minor Observations

- `Actor`、`Bearer Token`、`Native Hosted API v2` 与硬编码中文会破坏 en-US 模式一致性。
- 34px 控件高度若面向移动端，低于常见的 44px 触控建议。
- 全局搜索和公共仓库搜索主要依赖 placeholder，建议补 label。
- `PublicBrowse` 复用 `.ag-login-shell`，容易让两个 surface 的样式互相影响。
- 现有历史截图早于当前源码，只能证明过去的视觉问题，不能代替当前认证页的实时验收。

## Questions to Consider

- 390px 和 200% Zoom 下，管理控制台必须支持的最小闭环是只读值守，还是完整治理操作？
- Dashboard 是否应从五个同权指标改成一个待处理异常队列加次级容量信息？
- Artifact Gateway 最独特的视觉对象应该是仓库格式、信任来源、摘要完整性，还是“隔离 → 扫描 → 晋级 → 分发”的生命周期？
- 新用户能否在不查外部文档的情况下，在一分钟内选择正确的 Hosted、Proxy 或 Group？
