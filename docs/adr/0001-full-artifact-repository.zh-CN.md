# 完整制品库是产品边界

[English](0001-full-artifact-repository.md) · [文档索引](../README.zh-CN.md)

状态：已接受

Artifact Gateway 将从以只读穿透为主的网关演进为覆盖所有已支持格式的完整制品库。
“完整”包括 Hosted、Proxy 与 Group 生命周期，以及发布、不可变可见性、浏览与搜索、
逻辑删除、保留、晋升、复制、授权、审计和恢复。

这并不表示一次性加入所有包生态。只有在原生协议和完整生命周期契约都已定义后，
新格式才会被接纳。引入 V3 写模型能力时，现有读取兼容性保持稳定；新能力通过明确
契约和增量迁移逐步交付。
