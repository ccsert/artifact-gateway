构建权衡

总代码 gzip 从 493.8 KB 增至 515.9 KB（4.5%），但公开目录冷加载减少 15.5%，任务中心减少 12.1%。这是路由按需加载换取少量跨路由重复代码的明确权衡，首屏收益优先。

本轮实现

  • 新增跨仓库授权、生命周期任务和容量快照三个管理员批量端点。
  • PostgreSQL 容量按格式一次聚合；Maven Proxy 缓存索引一次扫描并以 8 个 worker 有界并发读取。
  • 访问控制与任务中心从 40 个 API 降为 3 个；总览和仓库列表移除逐仓库容量请求。
  • 任务中心启用 Ant Design Table 虚拟滚动，只渲染可见任务行。
  • 取消强制合并整包 Ant Design，使公开浏览页不再加载 315.5 KB gzip 的全量共享 chunk。
