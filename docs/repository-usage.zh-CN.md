# 仓库使用统计与 Console 分页

[English](repository-usage.md) | [文档索引](README.zh-CN.md)

## 使用统计接口

`GET /api/v2/repositories/{id}/artifact-usage` 要求仓库读取权限。`limit` 默认
100，允许 1–500；`offset` 默认 0，允许 0–1,000,000。`q` 是区分大小写的字面量
地址子串，去掉首尾空白，最多 512 个 Unicode 字符。非法文本、NUL 和非法数字
参数返回 400。`%`、`_` 与反斜杠没有通配含义。

响应的 `items` 只有当前页；`totalCount` 是所有匹配的（格式、地址）记录数；
`totals` 是全仓库累计总计，不随筛选改变。数量在 SQL 中计算，不拉取所有地址
来计数或分页。PostgreSQL 在同一个只读 repeatable-read 事务中读取响应各部分；
内存实现使用同一把读锁。

分页改为地址、格式的字节序升序，替代原来的下载量前若干条排名。下载次数增长
不会让已有记录换页。每次请求仍是实时视图，跨页期间新增地址可能移动 offset
边界；回到第一页可重新开始遍历。这不是跨请求持久快照或游标契约。深 offset 仍有
数据库成本，全仓库总计仍聚合该仓库全部统计行。

Console 首次请求 20 条，仅获取所选页。提交或清空地址搜索、更改页大小回到
第一页；刷新重载当前页，切换仓库重置视图。旧响应不会覆盖新查询。末页被删除
后，额外执行一次有界请求回到最后有效页。刷新失败保留旧数据并显示错误和重试。
没有匹配结果时仍显示全仓库总计。成功下载计数、组地址归属和不受审计保留影响
的口径保持不变。

## 共享分页与盘点

`ConsoleTable` 与 `useConsolePagination` 维护 Ant Design 6 基线：底部末端位置、
middle 控件大小、默认 20 条、20/50/100 选项、统一“第 1-20 项，共 100 项”文案。
页大小变化回第一页，受控服务端表同步重置查询；本地筛选组件负责重置页码。

| 页面 | 数据协议 | 共享展示 |
| --- | --- | --- |
| 用户、仓库使用统计 | 服务端 limit/offset，已知总数 | 数字分页、页大小选项及总数 |
| 漏洞明细、APT 包/删除/快照/导出选择 | 接口已经返回完整本地结果 | 本地数字分页，筛选回第一页 |
| 仓库、组、制品、全局搜索、保留策略试运行候选、服务账号及凭据、生命周期墓碑 | 服务端游标，未知总数 | 底部末端加载更多，不伪造总数或循环拉完 |
| 审计记录 | 有界服务端游标页，未知总数 | 底部末端上一页/下一页，仅显示页码与当前记录数，不加总数或循环拉完 |
| 配额规则仓库选择器 | 服务端游标，未知总数；按需追加 | 复用末端加载更多入口，保留表单选择行为，不伪造总数 |
| 扫描任务、仓库生命周期任务 | 最近 100 条生命周期任务，再按任务类型本地筛选 | 明确有界摘要及 `pagination=false`，不声称全部历史总数 |
| 运行日志 | 有界更早日志游标 | 同一底栏，保留“加载更早日志”和记录/字节上限 |
| 浏览树、协议原生及公共展开表 | 分支/协议游标或嵌套投影 | 保留分支加载入口及 `pagination=false` |
| 总览前十/近期行、授权、角色/模板、API Key、全局生命周期任务（最多 500 条）、计划任务、操作、节点、诊断、Webhook/投递、审计保留及嵌套详情 | 有界摘要或完整小列表 | 明确 `pagination=false`，不人为加数字分页 |

新增表格先选择真实数据协议，再启用分页。不能把已加载批次长度当作服务端
总数，也不能拉完游标页来模拟数字分页。本次不改造手机布局。
