# Console Nexus 迁移工作流

[English](nexus-migration-console.md) | [文档索引](README.zh-CN.md)

平台管理员打开 **运维 → 迁移源**。**连接与映射** 管理
[已保存的源](nexus-source-discovery.zh-CN.md)，**批次与验收** 读取并控制
[持久批次](nexus-migration-batches.zh-CN.md)。深链为
`/operations?tab=migrations&view=batches&batch=<批次 UUID>`，只包含标识符。
普通用户不能打开页面、深链或调用 API。

## 应用显式计划

运行源预检并预览所选映射。Hosted 动作将源和目标名称意图带入批次表单；也可直接
创建批次，或从已有批次选择 **重新扫描并追平**。每次启动都重新读取已保存的源，
要求预检与当前连接版本相符。

最多选择十个受支持的 Maven 发布版本、Raw、OCI 或 Conan 2 Hosted 源，逐个绑定真实、活动、同格式的
Hosted 目标。预览名称只有在当前仓库目录中已经存在时才会解析，不会当成虚构的
仓库 UUID。缺失目标需先在仓库管理中明确创建。应用映射将目标 ID 作为批次不可变
输入持久保存，不继承源策略、凭据、Group 成员或 Proxy 配置。

运行时能力接口返回真实对象目标和物理存储池 ID。容量是操作员报告的证据，不是
Gateway 测量或容量预留。六项字节值初始均为空，必须填写已知的非负精确整数；
明确为零可以填 0。观察/截止时间需带时区的 ISO 格式，观察不能在未来，有效窗口
最多一小时。未知、过期或绑定不一致会阻止执行。恢复/重试表单不预填旧证据，要求
严格更新的观察时间。不能用日志、临时目录或无关主机磁盘空间代替对象存储池证据。
下载峰值至少覆盖最大源资产的完整暂存大小。

## 观察与控制

扫描元数据、封存计划条目、唯一源总量、扫描阶段额外源校验、复制阶段源读取、
唯一目标读回字节和可见身份分别展示。总量缺失保持未知。额外源校验用于补齐清单
缺失摘要；复制字节包括重试和已有身份的重验；二者都不代表目标可见。本页不推断
百分比或宣称全部追平。冲突、失败、未支持、源缺失和源删除分别保留计数。

关闭浏览器或切出视图只是停止观察，worker 会继续。活跃详情与条目独立轮询，因为
字节/条目检查点不一定改变批次 CAS 版本。返回可见页面或刷新会重新读取服务端事实。
暂停会等待当前工作排空。恢复和重试需更新容量证据；重试是批次级操作，只重新排入
低于服务端尝试上限的失败/源缺失条目；未封存的失败扫描则可凭新证据在原批次完整
重扫。取消保留已发布内容，不删除源或目标数据。
新的追平批次会完整枚举并重验目标；源删除仅报告，不执行破坏性镜像删除。

源请求被拒绝（401/403）后，页面隐藏已加载的源元数据、预检和映射结果，并关闭
编辑、删除与批次草稿表单。换源、切换视图或重新打开面板不会恢复这些缓存；只有
拒绝之后发起并成功的重新读取才能恢复显示，随后还需重新预检和填写容量。
临时服务错误（500）保留上次已获授权的观察，并显示刷新失败提示。
登录令牌或身份变化时自动建立新的读取范围；旧身份的迟到响应不能恢复或拒绝新范围。

控制使用打开时捕获的 `If-Match` 版本，相同输入在当前表单中重试会复用
`Idempotency-Key`。版本冲突要求先读取当前批次。网络或服务端失败可能导致结果未知，
需先读取服务端，再判断是否以相同输入重试。命令成功后再 GET，因为幂等重放正文
可能含较旧检查点。打开、关闭、刷新或轮询页面都不会自动发出控制 POST。

## 阅读与导出验收观察

条目分页展示源/目标路径、精确大小、完整 SHA-256、尝试次数和目标校验标志。加载
所有分页后才能将库存视为完整。导出会重新读取批次、已加载库存页及目标详情，分别
记录批次/库存观察时间；扫描未封存、仍有游标或库存不齐时明确标为不完整。导出仅
投影有限服务端事实，不含源凭据、任意上游错误正文或下载验证器。

报告包含当前原生目标端点、对应格式的客户端配置例子、未支持/冲突计数及残余依赖。
**target-only 冷客户端证据** 和 **冻结源写入后的最后追平点** 保持 **未验证**，
因为批次 API 不提供这些验收证据。后台 `completed` 和服务端最后更新时间不能证明
它们；其它官方客户端 fixture 门禁也不能替操作员的具体批次验收。

切流前需明确冻结源写入方，执行最终完整重扫，核对异常，并以空缓存真实客户端只
连接目标验证。检查 Proxy/Group 依赖、未支持格式/SNAPSHOT、权限、发布凭据及
CI/客户端端点。目标出现新写入后，回退前必须核对并回补这些写入；只切回端点会
遗漏新增数据。本页不修改 CI/DNS/Ingress、不停用 Nexus，也不授权生产切流。

## 验证边界

状态测试覆盖精确容量/时效、源版本变化、真实目标绑定、CAS/幂等、同版本检查点刷新、
分页、安全导出及刷新保留/权限拒绝。真实路由布局门禁覆盖双主题 1440px/390px、
16/24px 有界间距、长摘要/路径及普通用户深链拒绝。Linux 视觉基线保留现有桌面
Ant Design 布局。

`console/e2e/nexus-batches-live.spec.ts` 是显式启用的独立 fixture 门禁。
将 `MIGRATION_BATCH_FIXTURE_CONFIG` 指向其隔离运行描述，Console 代理连接该
Gateway，并设置 `PLAYWRIGHT_EXTERNAL_SERVER=1` 和真实 `PLAYWRIGHT_PORT`。
描述文件标明合成源、目标、批准的 TLS/出站策略与独立 worker。测试拒绝非持有项目，
只为该测试显式测量 RustFS `/data` 真实池作为容量证据，不替产品用户填测量值。
门禁验证真实 API/PG/对象字节与 worker 行为；fixture 观察不等于真实 Nexus 库存、
远端 CI、生产切流或操作员批次的冷客户端证据。
