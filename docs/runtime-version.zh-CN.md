# 运行版本与节点构建身份

[English](runtime-version.md) | [文档索引](README.zh-CN.md)

管理端侧栏显示**当前连接节点**的构建版本和修订号，点击后进入“任务中心 → 系统诊断”。`GET /api/v2/diagnostics` 返回响应此请求的进程构建信息与会话 ID；负载均衡器切换后，这个值也可能变化。

`GET /api/v2/runtime/nodes` 返回所有仍在保留窗口内的节点会话。每次心跳会更新版本与修订号，节点清单同时展示角色、启动时间、最近心跳与运行状态。`currentSessionId` 指向响应此请求的 API 会话；清单中相同会话标为“当前连接节点”。

滚动升级时，在线或心跳陈旧的节点只要报告了不同版本或修订号，`health.issues` 就会包含 `mixed_build` 和相关会话 ID。旧版本节点可能没有构建字段；未报告完整身份时返回 `build_identity_unknown`，界面显示“版本未知”，不把它误判为某个已知版本。已离线节点不参与版本一致性判断。

`releaseSource: not_configured` 表示尚未接入预期版本或 Release 数据源。当前运行版本、集群节点版本与“最新版本”是不同概念；系统此时不会声称当前构建是最新版本。`dev` 构建在界面标为“开发构建”。

升级数据库时应用迁移 `000135_runtime_node_build_identity.sql`。新增字段允许为空，旧进程在滚动升级期间可继续写入心跳。回滚应用进程不需要删除新增字段。
